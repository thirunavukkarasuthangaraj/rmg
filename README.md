# RMG Enterprisses

Official website for **RMG Enterprisses** — Earth Mover, Housing & Land Developers, Valasaravakkam, Chennai.

## About
A trusted, experienced developer offering:
- 🚜 Earth Movers (JCB, excavation, levelling, site preparation)
- 🏠 Housing & Construction
- 🗺️ Land Development (layouts, plotting)
- 📜 Buying & Selling of plots and houses

## Tech
- Static **HTML + CSS + JavaScript** (no build step)
- Responsive, mobile-friendly
- **Tamil / English** language switch (`js/i18n.js`)
- Lord Murugan inspired peacock-green & gold theme with an animated Vel
